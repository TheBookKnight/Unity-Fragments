
# Unity Fragment: Player 2D Top Down Movement

This Unity fragment provides a modular script for 2D topdown player movement. When the player moves in any direction, the sprite will automatically rotate to face the direction of movement (e.g., northeast, southwest, etc.).

## Features
- Simple player controls for topdown 2D movement
- Sprite automatically faces the direction of movement
- Easy integration into any Unity 2D project

## Getting Started
1. **Copy this folder** into your Unity project's `Assets/` directory.
2. **Add the movement script to your player GameObject**
3. **Ensure your player GameObject has a Rigidbody2D component**

## Usage
- Assign the movement script to your player character.
- Use Unity's Input System or your preferred input method to control movement.
- The sprite will rotate to match the movement direction automatically.
